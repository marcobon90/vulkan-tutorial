# Vulkan Tutorial
This is my implementation of Vulkan tutorial.
Ref: https://docs.vulkan.org/tutorial/latest/00_Introduction.html

The main project and other example projects are in examples folder with the build and run instructions.

## Build and run a project
By terminal using cd examples/<name-project>

Build by Ninja using: 
- cmake -B build -S . -G Ninja
- cmake --build build

Run the project using: ./build/<nameApp>

You find the app name in the INSTRUCTIONS.md of the single project.
